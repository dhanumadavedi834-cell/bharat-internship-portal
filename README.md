# InternIndia - National Internship Platform

InternIndia is a modern, unified internship portal designed for Indian students. It facilitates seamless discovery, filter-based search, and application tracking across both Public Sector Undertakings (PSUs) / Government Ministries and Private Enterprises.

## Key Features

1. **Homepage & Navigation**: Modern navbar, hero section with live stats, PM Internship Scheme highlight, and government branding accents.
2. **Advanced Search & Filtering**: Filter opportunities by location, category, work mode, stipend, duration, and academic eligibility.
3. **Public & Private Opportunities**: Dedicated sections for government sector internships (e.g., NITI Aayog, ISRO, Ministries) and private corporations (e.g., TCS).
4. **Student Dashboard**: Live tracking of application status, saved internships, direct benefit transfer (DBT) details, and resume management.
5. **Responsive Design**: Built using Tailwind CSS for full accessibility across mobile, tablet, and desktop screens.
